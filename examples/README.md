# Примеры генерации изображений

Примеры сгенерированы через плагин `image_gen/polza` в Hermes Agent.

## Seedream 4.5 (дефолтная модель)

```
Промпт: "mountain landscape with cherry blossoms, photorealistic"
Аспект: square (1:1)
Цена: 5 ₽
```
